# v0.1.1：新增翻译功能开关

默认快捷键：

| 按键 | 功能 |
|---|---|
| Ctrl+Q | 启用／暂停翻译 |
| CapsLock | 开始框选／关闭译文 |
| , | 上一个词义 |
| . | 下一个词义 |

四个键均可在设置中修改。暂停关闭当前框选与译文，释放前三个快捷键，开关键仍有效。托盘显示启用状态，也可切换。恢复遇到按键占用时保持暂停，保留开关键供重试。

旧默认配置自动迁移；之前自定义的三个键保留。若自定义键占用Ctrl+Q，新开关键会选择不重复组合，以设置窗口为准。

升级前先从托盘退出旧版，再启动新版；两个版本共享单实例保护。v0.1.0文件、标签与Release保留。

验证：37项本地测试通过，独立代码复审通过，实际Windows默认按键与冲突回退验证通过；最终exe在D盘的离线、推理进程及开关自检全部通过，产品代码GitHub Windows测试通过。

模型与词典沿用v0.1.0。完整包已附带离线资源，不需要安装Python或配置在线服务。暂停保留已加载模型供恢复使用，退出才彻底结束推理进程。
