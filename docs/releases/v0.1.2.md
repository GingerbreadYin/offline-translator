# v0.1.2：窗口翻译与本地收藏

## 使用

退出托盘中的旧版本，解压完整的 `OfflineTranslator-v0.1.2-win-x64.zip` 后运行 `OfflineTranslator.exe`。请保留整个文件夹，离线模型已经包含在内。

- `Ctrl+Shift+A`：开启／关闭当前活动窗口的可见英文翻译。
- `Ctrl+Shift+S`：收藏翻译。全屏模式保存鼠标所指的一条译文；框选模式保存本次全部原文及当前译文／义项。
- 托盘右键 → “收藏列表”：查看英文、中文和收藏时间，支持删除。相同原文不重复，不同义项再次收藏会更新。
- `CapsLock`：框选／关闭；逗号、句号：上／下义项；`Ctrl+Q`：启用／暂停。六组按键均可修改。

## 显示与更新

按段落翻译，优先正文。译文优先放在原文上方；空间不足时在旁栏用编号对应。上方覆盖层支持鼠标穿透，旁栏可滚动。窗口最大化时旁栏可能覆盖屏幕边缘，可缩小原窗口留出空间。

画面变化时隐藏旧译文，稳定后刷新，重复文字使用缓存；切换窗口隐藏译文，回到原窗口重新检查。窗口关闭或最小化时停止。截图不落盘，翻译不联网。

## 数据与升级

旧快捷键保留并自动补充新功能键。收藏位于 `%LOCALAPPDATA%\OfflineTranslator\favorites.db`，设置位于同目录的 `settings.json`。重新解压软件不会删除这些数据。

本版本复用 MIT 许可的 Windows Capture 2.0.1；保留现有离线 OCR、词典和翻译模型。完整许可证与使用说明随包附带。

## 验证与限制

通过 55 项自动测试、独立代码审查，以及实际可执行程序的离线推理、独立工作进程、六键启用／暂停、原生窗口截图和受控窗口翻译／收藏／更新流程验证。

正文识别是截图启发式筛选，无法像浏览器扩展一样准确理解网页结构。持续动画可能推迟刷新；复杂漫画字体、真实混合 DPI 多屏阅读仍需进一步试用。取消会在当前识别／段落处理结束后停止剩余翻译，退出会终止工作进程。

两个新默认键可能覆盖浏览器原快捷键；可在设置修改，暂停后释放。
