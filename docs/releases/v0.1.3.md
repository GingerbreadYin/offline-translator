# v0.1.3：单次截图、拖动译文与快捷键修复

升级前先从托盘退出旧版本，再运行新文件夹里的 `OfflineTranslator.exe`。原来的快捷键和收藏保留。

## 改动

- 全屏翻译只截取按键时的画面，删除实时刷新、画面监听与持续截图线程；切页、滚动、切换窗口后译文不会变化或自动消失。
- 再按 `Ctrl+Shift+A` 或 Esc 关闭全屏译文；暂停、退出或切换翻译模式也会关闭。
- 框选译文、全屏独立译文框及编号列表均可按住顶部提示栏拖动。
- 修复长段落和无空格网址撑宽内容区、右侧裁切的问题，支持自动换行和纵向滚动阅读完整内容。
- 软件启动后在后台预热 OCR 与翻译模型；分批显示已完成的译文，补齐结果时保留拖动位置。
- 修复设置页切到后台后全局快捷键仍被停用的路径，覆盖最小化及迟到激活事件；引擎异常后，下次翻译按键可重新初始化，无须通过托盘恢复。
- 设置页新增“收藏列表”按钮，托盘入口仍保留。收藏规则不变。
- 移除 Windows Capture 依赖，使用原有 Qt 完成单次截图；翻译仍完全离线。

## 验证

本地及无桌面环境共 62 项测试通过；独立审查通过。受控原生窗口测试覆盖截图、页面变化后保留译文、4 轮原生快捷键开关、鼠标指向收藏和暂停。

对用户提供截图的相同裁剪区域进行本机计时：旧版冷 OCR 与翻译合计约 7.9 秒；后台预热后首次大图约 5.7 秒，重复处理约 3.4 秒。预热在启动后的后台进行，并未消除总计算成本；实际速度随文字量和电脑负载变化。模型与翻译搜索参数保持不变。

持续动画不会再触发重复任务；若要翻译新页面，请关闭旧译文后重新开启。复杂漫画字体和实际混合 DPI 多屏仍需更多真实样本验证。
