# 离线翻译工具第一版设计

日期：2026-10-16

状态：交互与方案已在聊天中确认；本书面设计待用户审阅。尚未进入实现。

## 1. 目的与用户

为使用 Windows 阅读英文的中文用户提供快速查词与短文本翻译。主要用户为英语六级约550分、词汇量约5000的大学生，主要内容包括 GitHub 文档、日常英文和英文漫画。减少截图、复制及询问 AI 的步骤，支持阅读过程中即时理解陌生词汇。

## 2. 已确认范围

- Windows 桌面软件，用户手动启动，启动后常驻系统托盘；退出后释放快捷键。
- 首次准备时允许联网下载模型和词典；准备完成后日常识别、查词与翻译全部本机离线运行。
- 采用本地 OCR＋离线词典＋专用英译中模型。
- 支持截图式矩形框选，识别英语，输出简体中文。
- 单词显示对应词性与一个简洁中文义项，默认显示词典排序最靠前的常见义项。
- 短语、句子和短段落显示简洁清晰、自然流畅的中文翻译。
- 截图、识别文字不发送到外部服务；默认不保存截图或翻译历史。

## 3. 操作流程

1. 用户打开软件；首次完成资源准备，进入设置绑定三个快捷键。
2. 按主快捷键进入框选模式，显示屏幕框选遮罩。
3. 用鼠标拖出矩形，松开鼠标即确认区域并自动开始识别、查词或翻译。
4. 在区域上方显示一个简洁结果框；空间不足时显示在下方，并限制在屏幕可见区域内。
5. 单词有多个义项时，用“上一个词义”和“下一个词义”快捷键切换。
6. 再按主快捷键，关闭结果。随后再按主快捷键可开始下一次框选。

Esc 随时取消框选、取消等待或关闭结果。框选状态再按主快捷键也取消本次操作；处理期间再按主快捷键关闭本次请求，迟到结果不得重新弹出。零面积框选不触发识别。

## 4. 三个可修改快捷键

| 动作 | 行为 |
|---|---|
| 主快捷键 | 空闲时开始框选；框选、处理中或显示结果时取消或关闭 |
| 上一个词义 | 单词结果显示上一个义项，到首项后循环到末项 |
| 下一个词义 | 单词结果显示下一个义项，到末项后循环到首项 |

设置界面允许录入单键或组合键，支持修改与持久保存。不能保证所有按键均可用：系统保留、无法注册或被占用的按键必须明确提示。三个动作不得使用重复绑定；修改失败保留原有效绑定。按住按键产生的重复事件不得连续开关界面或快速跳过义项。

词义切换仅在单词结果有多个义项时生效；单义词、句子结果和空闲状态不产生动作。绑定说明应提醒单键可能影响当前软件的正常输入。

## 5. 单词和句子显示

单词示意：

> issue · n. 问题

切换后可显示其他词性与义项，如“n. 议题”或“v. 发行”。示例只说明界面，不承诺具体词典的义项与排序。

- 每次只显示一个义项与对应词性，可附小型序号，如1/3。
- 常见义项按选定词典的排序显示，不宣称能够自动匹配当前上下文。
- 对词形变化先尝试词典直接查询，再尝试可靠的词形还原，保留用户识别到的原词。
- 无词典条目时回退到翻译模型，不编造词性或义项，不提供虚假的切换项。
- OCR 识别为单个英文词且词典可匹配时进入查词模式，其余进入文本翻译模式。
- 翻译要求保留术语、链接和代码标识符的原样文本，不改动源页面。截图方式不恢复链接的可点击属性，也不承诺重建原版式。
- 长结果允许结果框内部滚动，避免覆盖整个屏幕。

## 6. 界面与生命周期

主要界面包括简洁设置窗口、托盘菜单、框选遮罩和结果框。

设置窗口包含三个快捷键、资源准备状态、下载重试及资源检查。托盘菜单提供设置和退出。结果框展示处理状态、中文结果或简洁错误信息，尽量不抢走当前应用的键盘焦点。

软件退出时释放全局快捷键、关闭遮罩与结果框并停止后台工作。已下载资源保留供下次使用。

## 7. 组件与数据流

| 组件 | 职责 | 输入与输出 |
|---|---|---|
| 设置与快捷键 | 保存设置，注册快捷键，分发动作 | 按键事件→框选、关闭或切换 |
| 屏幕框选 | 获取指定屏幕区域，记录坐标 | 矩形→临时图像与位置 |
| OCR | 本机识别英文，整理必要换行 | 图像→英文文本 |
| 词典查询 | 查词、词形处理、整理词性和义项 | 单词→有序义项列表 |
| 翻译服务接口 | 封装本地翻译，预留未来联网实现 | 英文文本→中文译文 |
| 结果展示 | 定位窗口，显示状态与结果，切换义项 | 查询结果＋坐标→界面 |
| 资源管理 | 下载、校验、加载模型和词典 | 资源清单→可用本地资源 |

数据流：框选图像→OCR→文本分类→词典查询或本地翻译→结果框。识别与翻译在后台运行，界面保持可取消。每次任务使用独立标识，取消后忽略旧任务的返回结果。

截图仅在本机临时处理，完成或取消后释放；不写入普通日志。日志如有，仅记录不含内容的运行错误。未来联网翻译通过独立实现接入，默认行为与数据发送范围需要届时另行确认。

## 8. 硬件与资源准备

已读取用户电脑：AMD Ryzen 9 8940HX，16核32线程；约16GB内存；NVIDIA RTX 5060 Laptop约8GB显存；Windows 11家庭版64位；检查时D盘剩余约242GB。

优先选择适合短文本的轻量资源，保留CPU运行路径；是否使用GPU取决于运行库兼容性和实测收益。当前没有选定OCR引擎、词典、翻译模型、开发语言或打包方案。不得把硬件信息当作已验证性能。

资源下载应显示进度，支持失败后重试，校验文件完整性；未准备齐全时明确列出缺失资源。下载前展示总大小和来源；日常翻译不得触发隐式联网或在线回退。资源安装目录与最终安装包形式在实施计划中明确。

选择词典和模型前核实许可、离线运行能力、英文覆盖、义项排序、词性数据以及部署兼容性。

## 9. 异常与边界

- 无文字或识别失败：提示“未识别到英文，请重新框选”。
- 未查到词：回退到本地翻译，结果保持可关闭。
- 模型缺失或加载失败：提示具体缺失资源，并提供设置入口。
- 翻译失败：显示可理解的错误，不保留永远等待的状态。
- 下载时断网：保留已验证资源，允许重试；准备完成后的离线使用不依赖网络。
- 单键冲突、系统保留键：以注册验证结果为准，拒绝无效绑定。
- 多显示器、高DPI、屏幕边缘需要验证坐标与显示位置；不同缩放比例是重点测试场景。
- 受保护内容、特殊全屏界面可能无法截图，不承诺覆盖所有软件。
- 漫画艺术字体、低分辨率、小字号、竖排及弯曲文字存在OCR误差，需单独测试。

## 10. 第一版不包含

整页自动翻译、联网翻译、词汇统计、收藏与历史、云同步、音标、朗读、例句、上下文义项自动排序、自定义术语表及多种目标语言。未来优先考虑联网翻译和词汇统计；离线方案保持可独立使用。

## 11. 验收与待验证项目

| 项目 | 验证方式 | 通过条件 |
|---|---|---|
| 离线运行 | 准备资源后断网，重启软件并查词、翻译 | 完成流程，无外部翻译依赖 |
| 主流程 | 按主键，框选英文并松开鼠标 | 自动识别并显示中文，无需二次确认 |
| 关闭与取消 | 分别在框选、处理和结果阶段按主键或Esc | 关闭当前任务，旧结果不再次弹出 |
| 义项切换 | 使用多义词分别按两个切换键 | 每次切换一项，词性匹配义项，首尾循环 |
| 快捷键设置 | 改键、重启、设置重复或已占用按键 | 有效配置保留，无效配置有清晰提示 |
| 界面位置 | 屏幕上下边缘及不同缩放比例框选 | 结果可见，无明显越界或错位 |
| 词典缺词 | 框选未收录词及词形变化 | 合理查询或回退，不编造词性 |
| 识别效果 | 用户提供文档和漫画截图测试集 | 分别记录错误并确认可接受范围 |
| 翻译效果 | 用户确认单词、短语、句子示例 | 关键含义正确，中文简洁，术语不过度改写 |
| 响应与占用 | 实机记录冷启动、热查词、短句翻译 | 展示测量结果，由用户确认可接受阈值 |

具体响应秒数、模型大小及资源占用尚未承诺，应在选择资源与实机验证后确定。用户尚未提供理想翻译示例；实施前补齐代表性的单词、技术短句与漫画对白作为测试样本。
