# v0.1.2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** Offline active-window translation with nonblocking overlays and local learning favorites; release v0.1.2 to the user's private GitHub repository.
**Architecture:** Keep PySide6, RapidOCR, ECDICT and Argos. Validate Windows Capture first. Translate visible English paragraphs in a terminable worker, cache unchanged text, invalidate overlays on changes/focus loss. SQLite stores favorites independently from bundled read-only dictionary.
**Spec:** User decisions in this conversation, summarized below.

## Global constraints
- Six editable shortcuts: CapsLock, comma, period, Ctrl+Q, Ctrl+Shift+A, Ctrl+Shift+S. Migrate existing custom bindings without duplicates.
- Full translation targets the current foreground window's visible content. Click-through translations above original where safe; numbered side panel fallback when space is unavailable. Scroll/change hides stale results; stable content refreshes. Focus changes hide translations. Pause stops all translation features.
- Favor body paragraphs; skip obvious code/URLs/small controls heuristically. Preserve offline runtime. No new online service.
- Full-window favorite saves only hovered translation (including side panel); rectangle favorite saves complete result and current sense. Local list shows English, Chinese and saved time, supports deletion. Same original deduplicates; changed meaning updates existing row.
- User authorizes development and upload now and on future releases. Keep previous D: version intact.

## Review focus
- Stale inference after scroll, focus changes, settings, pause, cancel and window close.
- DPI, negative monitor coordinates, maximized windows and panel space.
- Overlay captured as source / feedback loops; transient self windows must not rebind target.
- Duplicate favorites, failed writes, mouse outside translation, and long text scrolling.
- Shortcut migration, atomic rollback, process shutdown and frozen-app dependencies.

## Tasks
1. Component probe and baseline: verify Windows Capture on a controlled test window and Python 3.12; record result. Branch feature/v0.1.2 in existing dedicated checkout (avoid duplicating bundled resources).
2. Core behavior TDD: add six-key migration tests, SQLite favorites persistence/upsert/delete tests, OCR block grouping/filtering and overlay placement tests; observe failures then implement modules core.py, favorites.py, fullpage.py.
3. Inference TDD: OCR boxes, paragraph translation caching, bounded worker requests and full mode results; preserve old region contract. Test offline generated English fixtures and canceled generations.
4. UI integration TDD: add active-window capture adapter, refresh coordinator, click-through full overlay + numbered panel, hover favorites, favorites dialog, six-key settings and tray entries. Test actual Qt event handling, focus/scroll invalidation and pause.
5. Verification: full pytest, local OCR/worker probes, full-window controlled native fixture, source UI smoke; independent branch review and fix findings. Build frozen portable app, repeat packaged probes and screenshot component capture.
6. Delivery: update version/changelog/README/notices, build complete ZIP/source/checksum, install alongside v0.1.1 on D:, commit and merge tested feature, push/tag v0.1.2 and publish private release. Verify uploaded asset hashes and CI.
