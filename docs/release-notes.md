# v0.1.0 首个离线试用版本

Windows x64便携包，解压后运行`OfflineTranslator.exe`。完整包已附带OCR、词典与英译中模型，无需安装Python，日常无需联网。

支持截图框选、本机识别、单词词性与默认义项、短句翻译，以及三个可修改快捷键。

默认操作：
- `Ctrl+Alt+Q`：开始框选，再按关闭译文。
- `Ctrl+Alt+Up` / `Ctrl+Alt+Down`：循环切换单词义项。
- `Esc`：取消或关闭。

设置窗口打开时暂停全局快捷键，保存或关闭窗口后启用。软件常驻托盘，右键可退出。

验证：27项本地测试通过，打包exe在D盘中文目录的离线资源、推理进程和界面启动退出检查通过；代码独立审查及GitHub Windows测试已执行。

仍需个人阅读试用：漫画艺术字体、复杂背景、双屏不同DPI、翻译质量。当前不支持跨两个显示器连续框选、联网翻译或词汇统计。默认义项按词典来源顺序，并不代表词义频率。

资产：Windows便携ZIP、SHA256校验文件、源码ZIP和中文使用说明。第三方资源来源与许可说明包含在包中。后续版本继续在本仓库迭代。
