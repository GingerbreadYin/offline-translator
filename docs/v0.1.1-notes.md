# v0.1.1：翻译功能启用与暂停

已确认交互：新增第四个可修改快捷键，按一次暂停翻译，再按恢复；暂停关闭当前框选和结果，释放其他三个快捷键。软件仍在托盘运行。托盘显示启用状态并允许点击切换。每次启动默认启用。

默认按键：Ctrl+Q 启用/暂停；CapsLock 框选/关闭；逗号键上一个义项；句号键下一个义项。全部可在设置中修改。

兼容旧设置：旧默认配置迁移到新默认；旧自定义三个键保持，补充不重复的开关键，若Ctrl+Q已用则优先Ctrl+Alt+S。保存采用原有原子写入逻辑。旧版本文件与Release保留。

验证覆盖：暂停释放原三键且开关键持续注册；恢复冲突后保持暂停并可再试；设置窗口打开/关闭不误恢复功能；取消后的旧结果不弹出；第四个Windows热键事件分发；配置迁移和冲突校验。全部原有离线与界面测试继续运行。

原始需求与设计仍见design.md；本文记录经用户批准的v0.1.1变更。暂停不卸载已加载的模型，正在执行的旧推理结束后结果被忽略，不再提交新翻译；退出才结束引擎进程。

## 验证记录

37项本地测试全部通过。实际Windows API注册CapsLock、逗号、句号、Ctrl+Q成功；暂停后模拟其他操作占用CapsLock，恢复失败时开关键保留，解除占用后可恢复。

独立审查发现并复现了设置窗口恢复失败丢失开关键、暂停前排队事件恢复后触发两项问题。回归测试先失败再通过；复审未发现其他Important/Critical问题。设置切换与退出会失效旧事件；连续两次开关键仍分别生效。

沿用原有离线资源，不改变模型和词典数据；v0.1.0目录、标签和Release保持原样。新版打包后仍需执行三项exe自检与D盘交付位置自检，记录随Release留存。
